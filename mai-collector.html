How to price a slab

1. Pick your grading company and grade below  ·  2. Tap Check eBay — look at the last 5 sales  ·  3. Use the middle price and type it in here.

Ignore active listings (asking prices, not sales) and any one sale way off from the rest. If there are only 1–2 recent sales, use the most recent and check again soon.

Your data — a file on this phone

Right now your collection is saved in this browser only — every browser keeps its own separate save, so a set added in the Google app will not appear in Chrome, or the other way round. Link a data file in a folder on this phone and the file becomes the real home: every change saves to it, any browser that opens the app and uses the same file sees the same collection, and the file survives browser switches, updates, and reloads. Inside a browser your save is still protected: a backup copy restores automatically if the main save is damaged, open tabs sync so one can’t erase another’s additions, and the app asks the browser for durable storage.

Pick any folder on the phone — Downloads is an easy one to find again. The file is small: a few kilobytes of text for a typical collection, well under a megabyte even with hundreds of scans. It stays on your phone unless you move it.

Prices

Singles & sealed: TCGplayer market prices from tcgcsv, pulled fresh each time a set is opened and re-pulled for every opened set when you refresh. Slabs: manual, from Slab Research only — never auto-refreshed.

Refreshing re-pulls each opened set’s price list from tcgcsv and updates prices only — quantities, check-offs, and where a card is filed never change, and no card ever moves.

About

Mai Collector, powered by Mai AI (recognition runs on this device — no Gemini, OpenRouter, Groq, OpenAI, or any other provider, no API key, no account). Hierarchy is Game – Category – Group – Product, with no Era level and no Bulk bucket: bulk is simply Collected quantity. Set lists and prices pull live from tcgcsv; lists you’ve opened are kept for the session so flipping between sets doesn’t re-pull them.

Mai Collector · Source data: tcgcsv.com (TCGplayer, updated daily) · The catalog loads on demand: tap + Add in Tracker to browse every game, category, and set on tcgcsv and add just what you collect — your list saves to your data file on this phone when one is linked in Settings, and in this browser only until then · A set’s cards and prices pull live from tcgcsv when the set is opened and stay cached after · Card images via TCGplayer CDN · Slab prices are manual — check eBay sold listings, never asking prices.
